# iris-random-forest-classification
Iris flower classification using Random Forest algorithm. Loads dataset, trains model, makes predictions with confidence scores. Built with Python &amp; scikit-learn.
## 📈 Model Performance Results

- **Accuracy Achieved**: 95.56%
- **Best Features**:
  - Petal Length: 48.8% importance
  - Petal Width: 42.3% importance
- **Sample Prediction**: Setosa with 100% confidence
